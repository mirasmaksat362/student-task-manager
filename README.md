# Student Task Manager

Student Task Manager – студенттердің оқу тапсырмаларын, пәндерін және дедлайндарын басқаруға арналған веб-жүйе.

## Жобаның мақсаты

Студенттердің барлық оқу тапсырмаларын бір жерде сақтау және дедлайндарды бақылауды жеңілдету.

## Негізгі функциялар

- Пайдаланушыны тіркеу
- Жүйеге кіру
- Пән қосу
- Тапсырма қосу
- Deadline белгілеу
- Priority таңдау
- Task status өзгерту
- Күнтізбе
- Хабарламалар

## Технологиялар

- Python
- Flask
- HTML
- CSS
- SQLite

## MVP

- Login
- Subjects
- Tasks
- Deadline
- Status
