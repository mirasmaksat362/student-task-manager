# ADR-001: Жеткізу моделін таңдау

## Статус

Қабылданды

## Контекст

Student Task Manager – студенттердің пәндерін, тапсырмаларын және дедлайндарын басқаруға арналған веб-жүйе.

Жобаның негізгі функциялары алдын ала белгілі, бірақ интерфейс пен кейбір қосымша мүмкіндіктер пайдаланушының кері байланысына байланысты өзгеруі мүмкін.

## Қаралған нұсқалар

### 1. Predictive

Артықшылығы:
- жоспар алдын ала анықталады;
- мерзімді бақылау оңай.

Кемшілігі:
- талап өзгерген кезде икемділігі төмен.

### 2. Adaptive

Артықшылығы:
- өзгерістерге тез бейімделеді;
- пайдаланушыдан жиі кері байланыс алуға болады.

Кемшілігі:
- жалпы жоспар жиі өзгеруі мүмкін.

### 3. Hybrid

Артықшылығы:
- негізгі жоспар алдын ала анықталады;
- функцияларды кезең-кезеңмен жасауға болады;
- пайдаланушы кері байланысын ескеруге болады.

## Шешім

Student Task Manager жобасы үшін Hybrid моделі таңдалды.

Негізгі мерзімдер мен MVP алдын ала жоспарланады, ал функциялар қысқа кезеңдермен жасалып, кері байланысқа қарай жетілдіріледі.

## Салдары

- MVP шекарасы алдын ала анық болады;
- әр кезеңде жұмыс істейтін нәтиже көрсетуге болады;
- пайдаланушы пікірі бойынша кей функцияларды өзгертуге болады;
- негізгі мерзімді сақтау қажет.
